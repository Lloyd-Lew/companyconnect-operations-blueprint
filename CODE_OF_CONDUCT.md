# Code of Conduct

CompanyConnect expects public interaction around this repository to remain professional, constructive, and respectful. Do not share confidential information, personal data, credentials, customer material, or abusive content. Report conduct concerns privately to [letsconnect@companyconnect.tech](mailto:letsconnect@companyconnect.tech?subject=Conduct%20concern%20-%20CompanyConnect%20Operations%20Blueprint).
