# Changelog

## [1.0.0] - 2026-08-18

Initial public release of the CompanyConnect Operations Blueprint: a client-safe, synthetic TypeScript reference system for lead intake, qualification, CRM-style opportunity, quote brief, approval, onboarding, operations, invoice trigger, support disposition, KPI aggregation, and audit events. Includes tests, CI, CodeQL, Dependabot, SBOM generation, security documentation, OpenAPI, Postman collection, Docker artefacts, developer runbook, and explicit operational boundaries.
